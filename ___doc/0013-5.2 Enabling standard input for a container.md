### musím použít veerzi 2.0
```yaml
# pod.kiada-stdin.yaml
apiVersion: v1
kind: Pod
metadata:
  name: kiada-stdin    
spec:
  containers:
  - name: kiada
    image: claivent/kiada:0.2     
    stdin: true    
    ports:
    - containerPort: 8080
```

```shell
kubectl apply -f pod.kiada-stdin.yaml
```
